# AGENTS.md

## Project Shape

- This is a Haskell compiler from a restricted LLVM-IR SSA subset to executable Haskell ANF.
- Main execution path: `app/Main.hs` -> `Lexer.x` -> `Parser.y` -> `Dominance` -> `Translate` -> `PrintAnf`.
- Keep `Ast.*` (LLVM side) and `Anf.*` (output side) distinct; many names like `Program`, `Function`, and `Call` exist in both modules.
- The supported LLVM subset is intentionally small: simple integer types only; no arrays, pointers, composites, I/O, syscalls, or side-effecting memory translation.
- All registers and blocks must be named except the entry block, which may be unlabeled and is relabeled by `Parser.y` using LLVM implicit numbering rules.

## Commands

- Build: `stack build`
- Full tests: `stack test`
- Focused tests: `stack test --test-arguments '--match "<describe or it text>"'`
- Translate a file: `stack run -- <file.ll> [-o <out.hs>]`
- Emit CFG DOT: `stack run -- --graph-viz <file.ll> [-o control-graph.dot]`
- Emit dominator-tree DOT: `stack run -- --dominance-viz <file.ll> [-o dominance.dot]`
- CI runs only `stack build` then `stack test`; there is no separate lint/format command configured.

## Build Config

- Edit `package.yaml`; `llvm-ir-to-functional.cabal` is generated by hpack and should not be hand-edited.
- `Lexer.x` and `Parser.y` are Alex/Happy sources; edit them, not generated parser/lexer output under build artifacts.
- The library uses strict warning flags in `package.yaml` (`-Wall` plus extra `-W...` flags), so keep `stack build` warning-clean.
- Stack is the canonical build interface; `stack.yaml` pins the Stackage resolver and CI enables Stack explicitly.

## Tests And Fixtures

- Test discovery uses `test/Spec.hs` with `hspec-discover`; add new `*Spec.hs` modules under `test/` with exported `spec`.
- `test/ExamplesSpec.hs` parses every top-level `examples/*.ll`; example subdirectories are ignored.
- Parser tests often force `printProgram . translate` so lazy translation errors surface; preserve that pattern for phi/control-flow regressions.
- Useful focused examples: `stack test --test-arguments '--match "unlabeled entry block"'` and `stack test --test-arguments '--match "parses all examples"'`.

## Translation Gotchas

- Name normalization happens during parsing in `NameNormalizer`: locals and block labels become Haskell identifiers prefixed with `a`, while globals drop punctuation without the local prefix.
- Dominator-tree nesting drives ANF scope: `Dominance.dominance` inverts `iDom` edges so edges point dominator -> dominated, and `Translate.anfFromTree` walks successors from node `0`.
- Phi nodes become lambda parameters; branch targets become tail calls whose arguments are selected from the target block's phi entries using the current source block label.
- `icmp` prints integer booleans (`if ... then 1 else 0`); conditional branches and `select` test values with `/= 0`.
- Some unsupported subset paths are deliberately commented or partial (`undefined`/`error`); do not make them broad/general without extending parser, translator, printer, and tests together.
